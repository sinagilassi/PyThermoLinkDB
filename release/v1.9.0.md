# 🚀 PyThermoLinkDB v1.9.0

This release introduces the **thermo model source workflow**: a higher-level way to build, validate, inspect, map, and register thermodynamic data from model sources, custom sources, matrix data, equations, and constants.

The new examples in `examples/thermo_model_source/` show the full workflow from source construction to runtime access and source registry selection.

## ⚡ Quick Start

The main v1.9.0 workflow is to build one thermodynamic source container, inspect the available symbols, validate the selected sources, and register the exact source to use for each thermodynamic property.

```python
from pyThermoLinkDB.builders import build_thermo_source_hub
from pyThermoLinkDB.models import CustomSourceConfig, ModelSourceConfig, SourceConfig

thermo_source_hub = build_thermo_source_hub(
    components=[C2H4, C2H6, CO2],
    component_key="Formula-State",
    mixtures=[[CH3OH, C2H5OH]],
    mixture_key="Name",
    model_source=model_source,
    custom_source=custom_source,
    model_source_config=ModelSourceConfig(
        data=["EnFo_IG", "Tc", "Pc"],
        equations=["Cp_IG", "VaPr"],
        matrix_data=["a", "b", "c", "alpha"],
        constants=["R", "dH_rxn"],
    ),
    custom_source_config=CustomSourceConfig(
        data=["MW", "Cp_IG", "Cp_LIQ", "rho_LIQ"],
        matrix_data=["CUSTOM_MATRIX", "CH4|C2H6"],
        constants=["dH_rxn", "Cp_LIQ_MIX_VOL", "R"],
    ),
)

thermo_source_registry = thermo_source_hub.register_thermo_source(
    thermo_source_hub_config={
        "Tc": SourceConfig(source="model_source"),
        "Cp_IG": SourceConfig(source="custom_source"),
        "VaPr": SourceConfig(source="model_source"),
        "alpha": SourceConfig(matrix_data_source="model_source"),
        "CUSTOM_MATRIX": SourceConfig(matrix_data_source="custom_source"),
        "R": SourceConfig(constants_source="model_source"),
    },
    components=[C2H4, C2H6, CO2],
    mixtures=[[CH3OH, C2H5OH]],
)

tc_source = thermo_source_registry["Tc"]["src"]
cp_ig_source = thermo_source_registry["Cp_IG"]["src"]
alpha_matrix_source = thermo_source_registry["alpha"]["src"]
```

## 🌟 Feature Snapshot

- 🧩 **Thermo model source**: build a compact `ThermoModelSource` from `ModelSource`.
- 🧪 **Custom thermo source**: build a `ThermoCustomSource` from dictionaries, `CustomProperty`, `CustomConstant`, and `CustomMatrixData`.
- 🏗️ **Thermo source hub**: combine model and custom thermodynamic sources in one access layer.
- ✅ **Validation reports**: check source completeness, requested symbols, component coverage, and issue lists.
- 🔍 **Runtime getters**: access data, equations, constants, matrix data, modes, and source objects directly.
- 🧭 **Mapping utilities**: map source dictionaries into component-ordered values and equations.
- 🗃️ **Source registry**: select the authoritative source for each symbol.
- 📝 **String config support**: define model, custom, and registry configs with YAML/JSON strings.

## 🧩 Thermo Model Source Builder

`build_thermo_model_source()` builds a compact `ThermoModelSource` from an existing `ModelSource`.

- 📊 Select component data with `requested_data`, such as `EnFo_IG`, `Tc`, and `Pc`.
- 🧮 Select component equations with `requested_equations`, such as `Cp_IG` and `VaPr`.
- 🧱 Select constants with `requested_constants`, such as `R` and `dH_rxn`.
- 🔢 Select mixture matrix data with `requested_matrix_data`, such as `a`, `b`, `c`, and `alpha`.
- 🏷️ Configure component and mixture IDs with `component_key` and `mixture_key`.
- 🛠️ Use `mode='silent'`, `mode='log'`, or `mode='attach'` to control build behavior.
- 🗂️ Access each resolved symbol through the unified `thermo_src` dictionary.

```python
from pyThermoLinkDB.builders import build_thermo_model_source

thermo_model_src = build_thermo_model_source(
    model_source=model_source,
    components=[CO2, C2H5OH],
    component_key="Name-State",
    mixtures=[[CH3OH, C2H5OH]],
    mixture_key="Name",
    requested_data=["EnFo_IG", "Tc", "Pc"],
    requested_equations=["Cp_IG", "VaPr"],
    requested_matrix_data=["a", "b", "c", "alpha"],
    requested_constants=["R", "dH_rxn"],
)

tc_values = thermo_model_src.thermo_src["Tc"]["value"]
cp_ig_equations = thermo_model_src.thermo_src["Cp_IG"]["eq"]
```

Examples: `examples/thermo_model_source/exp-1.py`, `exp-1-2.py`, and `exp-2.py`

## 🧪 Custom Thermo Source Builder

`build_custom_model_source()` builds a `ThermoCustomSource` from user-defined thermodynamic content.

- 🧬 Build component-wise custom data such as `MW`, `Cp_IG`, `Cp_LIQ`, and `rho_LIQ`.
- 🔢 Build custom matrix data with `CustomMatrixData`.
- 🧱 Build constants from `CustomConstant` and scalar `CustomProperty` entries.
- 🗂️ Store custom source records in the same `thermo_src` shape used by model sources.
- 🔍 Inspect source objects, raw values, and selected modes per symbol.

```python
from pyThermoLinkDB.builders import build_custom_model_source

custom_model_src = build_custom_model_source(
    components=[C2H4, C2H6, CO2],
    component_key="Formula-State",
    custom_source=custom_source,
    requested_data=["MW", "Cp_IG", "Cp_LIQ", "rho_LIQ"],
    requested_matrix_data=["CUSTOM_MATRIX", "CH4|C2H6"],
    requested_constants=[
        "dH_rxn",
        "Cp_LIQ_MIX_VOL",
        "R",
        "CUSTOM_CONST",
        "ANOTHER_CONST",
        "THIRD_CONST",
    ],
    mode="log",
)

mw_values = custom_model_src.thermo_src["MW"]["value"]
custom_matrix = custom_model_src.thermo_src["CUSTOM_MATRIX"]["src"]
```

Examples: `examples/thermo_model_source/custom_source_1.py`, `exp-3.py`, and `exp-3-1.py`

## 🏗️ Thermo Source Hub

`build_thermo_source_hub()` builds a `ThermoSourceHub` that combines model-source and custom-source content in one container.

- 🔗 Combine `model_source` and `custom_source` in a single thermodynamic source hub.
- 📋 Configure model-source extraction with `ModelSourceConfig`.
- 🧾 Configure custom-source extraction with `CustomSourceConfig`.
- 📦 Include component data, equations, matrix data, and constants in the same hub.
- 🧭 Inspect source types with `thermo_source_hub_types`.
- 🏷️ Inspect available symbols with `model_source_symbols` and `custom_source_symbols`.
- 🎯 Inspect symbol modes with `model_source_symbol_modes` and `custom_source_symbol_modes`.

```python
from pyThermoLinkDB.builders import build_thermo_source_hub
from pyThermoLinkDB.models import CustomSourceConfig, ModelSourceConfig

thermo_source_hub = build_thermo_source_hub(
    components=[C2H4, C2H6, CO2],
    component_key="Formula-State",
    mixtures=[[CH3OH, C2H5OH]],
    mixture_key="Name",
    model_source=model_source,
    custom_source=custom_source,
    model_source_config=ModelSourceConfig(
        data=["EnFo_IG", "Tc", "Pc"],
        equations=["Cp_IG", "VaPr"],
        matrix_data=["a", "b", "c", "alpha"],
        constants=["R", "dH_rxn"],
    ),
    custom_source_config=CustomSourceConfig(
        data=["MW", "Cp_IG", "Cp_LIQ", "rho_LIQ"],
        matrix_data=["CUSTOM_MATRIX", "CH4|C2H6"],
        constants=["dH_rxn", "Cp_LIQ_MIX_VOL", "R"],
    ),
)

print(thermo_source_hub.model_source_symbols)
print(thermo_source_hub.custom_source_symbol_modes)
```

Examples: `examples/thermo_model_source/exp-4.py`, `exp-5.py`, `exp-6.py`, `exp-7.py`, and `exp-8.py`

## ✅ Source Validation

The hub examples add validation helpers for checking whether requested model and custom sources are complete.

- ✅ `is_model_source_valid()` checks overall model-source validity.
- 📌 `has_all_model_requested()` checks requested model symbols.
- 🧩 `has_all_model_components()` checks model component coverage.
- ✅ `is_custom_source_valid()` checks overall custom-source validity.
- 📌 `has_all_custom_requested()` checks requested custom symbols.
- 🧩 `has_all_custom_components()` checks custom component coverage.
- 📄 `validation_summary()` returns a compact validation summary.
- 🔎 `validate_sources()` returns detailed validation reports and issue lists.

```python
print({
    "model_valid": thermo_source_hub.is_model_source_valid(),
    "model_all_requested": thermo_source_hub.has_all_model_requested(),
    "model_all_components": thermo_source_hub.has_all_model_components(),
    "custom_valid": thermo_source_hub.is_custom_source_valid(),
    "custom_all_requested": thermo_source_hub.has_all_custom_requested(),
    "custom_all_components": thermo_source_hub.has_all_custom_components(),
})

reports = thermo_source_hub.validate_sources()
print(thermo_source_hub.validation_summary())
print(reports["model_source"].issues)
```

Example: `examples/thermo_model_source/exp-5.py`

## 🔍 Runtime Access Helpers

`ThermoSourceHub` now provides direct access helpers for data, equations, matrix data, constants, modes, and values.

- 🗂️ `get()` returns a full source entry for a symbol.
- 🎯 `get_item()` returns one field from a source entry.
- 🏷️ `get_mode()` and `has_mode()` inspect the resolved mode for a symbol.
- 📊 `get_comp_dt()` returns component-wise data values.
- 🧬 `get_comp_src()` returns component-wise source objects.
- 🔢 `get_comp_values()` returns ordered component values.
- 🧮 `get_comp_eq()` returns component-wise equation sources.
- 🧾 `get_matrix_data_src()` returns model or custom matrix source objects.
- 🔢 `get_matrix_data_value()` returns the raw matrix data value.
- 🧱 `get_const()` and `get_const_src()` return constant values and source objects.

```python
tc_entry = thermo_source_hub.get(
    source_name="model_source",
    symbol="Tc",
)

mw_values = thermo_source_hub.get_comp_values(
    source_type="custom_source",
    symbol="MW",
)

cp_ig_eq = thermo_source_hub.get_comp_eq(
    source_type="model_source",
    symbol="Cp_IG",
)

r_value = thermo_source_hub.get_const(
    source_type="model_source",
    symbol="R",
)
```

Examples: `examples/thermo_model_source/exp-4.py` and `exp-5.py`

### 🧮 Get Equation Sources and Calculate

```python
from pyThermoLinkDB.utils.input_builder import validate_and_build_inputs

runtime_inputs = {
    "T": {"value": 25.0, "unit": "C"},
    "P": {"value": 101325.0, "unit": "Pa"},
    "Tc": {"value": 302.0, "unit": "K"},
}

cp_ig_sources = thermo_source_hub.get_comp_eq(
    source_type="model_source",
    symbol="Cp_IG",
)

for component_id, equation_source in cp_ig_sources.items():
    input_args = validate_and_build_inputs(
        equation_source.inputs,
        runtime_inputs,
        unit_conversion_fn=pycuc.convert_from_to,
        unit_availability_fn=pycuc.is_unit_available,
    )
    result = equation_source.calc(**input_args)
    print(component_id, result)
```

## 🧭 Source Mapping Utilities

The examples show how to map source dictionaries into component-ordered outputs for downstream calculations.

- 🧪 `map_prop()` maps component property sources to component-keyed data and ordered values.
- 🧮 `map_eq()` maps component equation sources to component-keyed data and ordered equations.
- 🔁 Unit conversion can be applied during property mapping with a conversion function such as `pycuc.convert_from_to`.
- 🔀 Component output can be reordered by passing a different `components` list.

```python
from pyThermoLinkDB.utils.thermo_source_tools import map_eq, map_prop

mw_source = thermo_source_hub.get_comp_src(
    source_type="custom_source",
    symbol="MW",
)

mw_by_component, mw_values = map_prop(
    data=mw_source,
    components=[C2H4, C2H6, CO2],
    component_key="Formula-State",
    output_unit="kg/mol",
    unit_conversion_fn=pycuc.convert_from_to,
)

cp_ig_by_component, cp_ig_equations = map_eq(
    data=thermo_source_hub.get_comp_eq(
        source_type="model_source",
        symbol="Cp_IG",
    ),
    components=[C2H4, C2H6, CO2],
    component_key="Formula-State",
)
```

Example: `examples/thermo_model_source/exp-5.py`

## 🗃️ Thermo Source Registry

`register_thermo_source()` resolves the source to use for each thermodynamic symbol and returns a selected source record.

- 🎚️ Select source ownership per symbol with `SourceConfig`.
- 🧭 Use explicit mode-specific selectors such as `matrix_data_source` and `constants_source` when needed.
- ⚡ Use the compact `source` selector when the mode can be inferred.
- 🧩 Use `include_missing=True` to include missing registry fields in the returned structure.
- 📦 Registered entries expose the selected source under `src` and the inferred source mode under `mode`.

```python
from pyThermoLinkDB.models import SourceConfig

thermo_source_registry = thermo_source_hub.register_thermo_source(
    thermo_source_hub_config={
        "Tc": SourceConfig(source="model_source"),
        "Cp_IG": SourceConfig(source="custom_source"),
        "VaPr": SourceConfig(source="model_source"),
        "alpha": SourceConfig(matrix_data_source="model_source"),
        "CUSTOM_MATRIX": SourceConfig(matrix_data_source="custom_source"),
        "R": SourceConfig(constants_source="model_source"),
    },
    components=[C2H4, C2H6, CO2],
    mixtures=[[CH3OH, C2H5OH]],
)

tc_src = thermo_source_registry["Tc"]["src"]
alpha_mode = thermo_source_registry["alpha"]["mode"]
```

Examples: `examples/thermo_model_source/exp-6.py`, `exp-7.py`, and `exp-8.py`

## 📝 String Configuration Support

Hub and registry configuration can now be provided as YAML or JSON string content.

- 🧾 Pass string content for `model_source_config`.
- 🧾 Pass string content for `custom_source_config`.
- 🧾 Pass string content for `thermo_source_hub_config`.
- 🔄 Convert registry string content directly with `thermo_source_hub_config_from_str()`.
- ⚡ Use shorthand entries such as `Tc: model_source` and `Cp_IG: custom_source`.
- 🎯 Use explicit nested entries such as `alpha: { matrix_data_source: model_source }` when mode selection must be forced.

```python
model_source_config = """
data:
  - EnFo_IG
  - Tc
  - Pc
equations:
  - Cp_IG
  - VaPr
matrix_data:
  - a
  - b
  - c
  - alpha
constants:
  - R
  - dH_rxn
"""

thermo_source_hub_config = """
Tc: model_source
Pc: model_source
EnFo_IG: model_source
Cp_IG: custom_source
VaPr: model_source
alpha:
  matrix_data_source: model_source
CUSTOM_MATRIX:
  matrix_data_source: custom_source
R:
  constants_source: model_source
"""

thermo_source_hub = build_thermo_source_hub(
    components=components,
    component_key="Formula-State",
    mixtures=mixtures,
    mixture_key="Name",
    model_source=model_source,
    custom_source=custom_source,
    model_source_config=model_source_config,
    custom_source_config=custom_source_config,
)

registry = thermo_source_hub.register_thermo_source(
    thermo_source_hub_config=thermo_source_hub_config,
    components=components,
    mixtures=mixtures,
)
```

Examples: `examples/thermo_model_source/exp-7.py` and `exp-8.py`

## 🔢 Matrix Data Workflows

The thermo model source workflow extends matrix data access across model and custom sources.

- 🧮 Extract matrix data from a `ModelSource` for configured mixtures.
- 🧪 Extract custom matrix data from `CustomMatrixData`.
- 🔍 Inspect matrix source summaries and property symbols.
- 🔠 Build alphabetic matrix views with `matX()`.
- 🗃️ Register matrix symbols from either `model_source` or `custom_source`.

```python
alpha_src = thermo_source_hub.get_matrix_data_src(
    source_type="model_source",
    symbol="alpha",
)

for mixture_id, matrix_source in alpha_src.items():
    print(matrix_source.summary())
    print(matrix_source.matX(
        components=[CH3OH, C2H5OH],
        symbol_format="alphabetic",
        component_key="Name",
        mixture_key="Name",
    ))

custom_matrix_value = thermo_source_hub.get_matrix_data_value(
    source_type="custom_source",
    symbol="CUSTOM_MATRIX",
)
```

## 🧱 Model Source Construction Examples

The example folder also documents how the underlying `ModelSource` is assembled before it is consumed by the thermo source builders.

- 🧬 Build component model sources from `ComponentThermoDB`.
- 🧱 Build constants model sources from `ConstantsThermoDB`.
- 🔢 Build mixture model sources from `MixtureThermoDB`.
- 🔗 Combine component, constants, and mixture model sources with `build_model_source()`.
- 📚 Use shared component definitions and reference content to build reproducible example sources.

```python
from pyThermoLinkDB import build_model_source

sources = [constants_model_source] + component_model_source + [mixture_model_source]

model_source = build_model_source(source=sources)

datasource = model_source.data_source
equationsource = model_source.equation_source
constantssource = model_source.constants_source
```
